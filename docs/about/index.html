AX 경험담.

AI로 일하는 방식을 바꾸며 배우고 생각한 것들.

AX Notes는 AI Transformation을 실제 업무에 적용하면서 얻은 생각, 시행착오, 기술적 실험과 프로젝트를 기록하는 개인 미디어입니다.

직접 써보고, 직접 만들어보고, 성공과 실패를 다른 사람이 활용할 수 있는 형태로 남깁니다. AX를 직접 해보는 사람의 기록입니다.

생각 하나는 Note, 이어 탐구하면 Series, 목표와 결과물을 만들면 Project.

글과 Project의 진행 과정을 따라가 보세요. 글 상세에서 X에는 기술과 Insight를, Threads에는 경험과 고민을 공유할 수 있습니다. 새 글은 RSS로 받아볼 수 있습니다.
