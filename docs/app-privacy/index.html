앱 개인정보처리방침

AX Notes Android 앱 · net.msalt.axnotes

운영자: 맛소금(msalt.net) · 문의: msalt.net.help@gmail.com

시행일: 2026년 10월 24일

1. 기기에 저장하는 정보

AX Notes는 회원가입 없이 이용할 수 있습니다. 북마크, 글에 연결된 개인 메모, 읽기 알림, 검색과 읽기 환경 설정 및 내려받은 콘텐츠는 기기에 저장됩니다. 개인 메모와 검색어를 운영자 서버로 전송하지 않습니다.

현재 앱에는 광고 SDK, 이용 분석 SDK, 계정 동기화, 클라우드 백업 및 기기 이전 기능이 없습니다. 운영자가 앱을 통해 이름, 이메일 주소, 연락처 또는 위치 정보를 입력받는 기능도 없습니다.

2. 인터넷 연결과 호스팅

글 목록·본문·이미지를 가져올 때 콘텐츠 호스팅 서비스에 인터넷 요청을 보냅니다. 이 요청에는 IP 주소 등 통신에 필요한 기술 정보가 포함됩니다. AX Notes 콘텐츠를 제공하는 GitHub Pages는 서비스 보안을 위해 방문자의 IP 주소를 기록·보관한다고 안내합니다. 이 정보를 북마크나 개인 메모와 함께 전송하지 않습니다.

호스팅 제공자의 처리 방식은 GitHub 개인정보처리방침과 GitHub Pages 안내를 참고하세요. 외부 이미지와 링크의 제공자는 콘텐츠에 따라 달라질 수 있습니다.

3. 알림 권한

설정한 읽기 알림을 표시하기 위해 알림 권한을 요청할 수 있습니다. 권한을 거부해도 글 읽기와 개인 기록 기능을 이용할 수 있습니다. 권한은 Android 시스템 설정에서 변경할 수 있습니다.

4. 외부 링크와 공유

외부 링크를 열거나 다른 앱으로 공유하면 해당 서비스의 개인정보처리방침이 적용됩니다. 공유는 사용자가 직접 선택한 경우에 수행되며, 개인 메모를 자동으로 공개하거나 다른 사용자와 교환하는 기능은 없습니다.

5. 보관과 삭제

기기에 저장된 개인 기록은 사용자가 삭제할 때까지 유지됩니다. 앱 내 삭제 기능, Android 앱 데이터 초기화 또는 앱 삭제로 지울 수 있습니다. 자동 백업이 없으므로 삭제한 기록은 복구할 수 없습니다. 콘텐츠 캐시와 개인 기록은 별도로 삭제할 수 있습니다.

호스팅 제공자의 보안 로그 보관 기간은 해당 제공자의 정책을 따르며, 운영자가 그 기간을 직접 설정하지 않습니다.

6. 문의

이메일로 문의하면 회신 주소와 문의 내용을 답변 및 문제 해결에 사용합니다. 개인 메모나 민감한 정보는 보내지 않아도 됩니다. 문의 이메일의 삭제 요청과 개인정보 관련 질문은 msalt.net.help@gmail.com으로 보내주세요.

7. 방침 변경

기능이나 정보 처리 방식이 바뀌면 이 페이지에 변경된 방침과 시행일을 안내합니다.
