프롬프트를 고치기 전에 입력부터 정리하기

결과가 흔들릴 때 확인해 볼 입력 정리 습관 세 가지.

TIP2026-09-24·Agent / AI Coding

이 글은 사이트 동작을 확인하기 위한 샘플 팁입니다. 실제 도구 사용 가이드가 아닙니다.

결과가 기대와 다르면 지시문을 길게 고치기 쉽습니다. 그 전에 입력을 정리하면 문제의 원인이 더 빨리 보일 때가 있습니다.

  1. 원본과 요구사항을 분리합니다. 참고할 자료와 원하는 출력을 한 문단에 섞지 않습니다.
  2. 예외를 한 번에 하나씩 추가합니다. 예외가 여러 개면 어떤 조건이 결과를 바꾸었는지 알기 어렵습니다.
  3. 완료 예시를 짧게 적습니다. 형식이 중요한 작업이라면 한 개의 좋은 예시가 긴 설명보다 분명합니다.

입력이 정돈되면 모델의 결과도 검토하기 쉬워집니다. 프롬프트 개선은 그다음입니다.
