무료 클라우드 컴퓨타 사용하기!

nanobot 같은 개인용 Agent를 상시 운영할 때 무료 VM과 호스팅 서비스를 고르는 기준.

2026-09-30·Agent / Cloud / Self Hosting

클라우드에 챗봇 하나씩은 다들 돌리고 계시죠? 요즘 워낙 다양한 상용 서비스가 있어서 딱히 직접 돌릴 필요를 못 느끼시는 분들도 계시지만, 그래도 하나쯤은 간단한거라도 필요할 때가 있더라구요. 서버가 클라우드에 있으면 간단한 이벤트를 릴레이해주기도 좋고, 여러모로 쓸모가 많아서 오래 전부터 AWS Free tier를 사용했었습니다. 1년 무료인데, 서버 말고 DB나 lambda 같은 서비스도 일정량 무료로 제공해서 참 좋았는데, 그 혜택이 대폭 축소 되었더라구요.🤦‍♀️

그 와중에 대안으로 찾은게 OCI 입니다. 오라클 클라우드 인프라스트럭쳐! 솔직히 처음 셋업할 때 진짜…x구렸는데, AWS랑 사용성 저하 체감이 너무 심해서 당황했는데, 요즘은 codex가 있잖아요. 도움을 받아가면서 셋업하고, 그 뒤로 운영까지 휘리릭~ 클라우드에 있으니 전력이나 추가 비용, 보안 문제도 많이 않고 여러모로 참 좋습니다. 오늘은 일단 OCI 포함 몇 개 서비스 소개시켜 드릴께요. 그리고 다음에는 거기에 올려서 사용할 만한 프로젝트를 소개시켜 드릴께요.😉

이번에 알아본 건 nanobot처럼 가벼운 Agent를 올려 두고, 필요할 때 외부 LLM API를 호출하는 용도입니다. 모델까지 서버에서 직접 돌릴 생각이라면 얘기가 달라지지만, 이 정도 용도라면 GPU보다 계속 켜 둘 수 있는 서버와 데이터를 남길 저장 공간이 더 중요하더라구요. 물론 서버가 무료라고 OpenAI나 OpenRouter 같은 모델 API까지 무료가 되는 건 아닙니다. 이 비용은 따로 봐야 해요.

2026년 9월 30일 기준으로 살펴보니, 제일 먼저 눈에 들어온 건 OCI Always Free였습니다. 무료 A1 인스턴스를 만들 수만 있다면 꽤 넉넉하게 쓸 수 있거든요. 문제는 그 자리가 좀처럼 나지 않는다는 것. 제 경험상 사양만 보고 가입하기보다는, 내 홈 리전에서 실제로 만들 수 있는지부터 확인하는 게 좋겠습니다. 여의치 않다면 Google Cloud Free Tier도 괜찮은 대안입니다. AWS말고 UX가 구린건 매한가지 입니다

서비스무료로 쓸 수 있는 컴퓨터기간제 느낌은요
Oracle OCIAmpere A1 총 2 OCPU·12GB RAM 상당Always Free사양은 넉넉하지만 무료 A1 자리를 구하기가 어렵습니다. 유휴 VM 회수 가능성도 있어요.
Google Cloud미국 3개 리전의 e2-micro 1대·표준 디스크 30GBFree Tier작지만 챗봇 하나 돌리기에는 살펴볼 만해요.
Azure지정된 B 시리즈 VM 월 750시간신규 계정 12개월1년 정도 실험하기 좋아요.
AWS신규 계정 크레딧 최대 200달러무료 계정 플랜 최대 6개월이제는 기간을 정해 두고 써야 해요.

표에는 서버 사양만 간단히 적었습니다. 실제로 만들 때는 디스크와 네트워크도 무료 범위에 들어오는지 꼭 확인해야해요. 서버만 무료이고 다른 자원에서 요금이 나올 수 있으니까요. 클라우드 안에서 데이터 전송에도 과금이 되고, S3 같은 스토리지에 파일만 올려놔도 과금이 되는데, DB 자동 백업 설정을 잘 못 해놓으면 S3에 스냅샷이 쌓여서 요금이…

그래서 지금 제가 사용하고 있는 것은 OCI입니다. Always Free 사양이 그나마 가장 마음에 들고, 평생 무료라는것이 완전 혜자입니다. 무료 사양에 암페어랑 AMD Micro VM이 있는데, 암페어는 거의 잡기가 힘들더라구요. AMD 마이크로 VM 2개 사용 중인데, 만족하고 있습니다. 찾아보니까 더 줄었네요;

오라클, Ampere A1 인스턴스 무료 사용 한도 축소

기존 최대 4OCPU + 24GB 메모리에서 최대 2OCPU + 12GB 메모리로 축소.

Google Cloud e2-micro는 제 용도에는 너무 작고 SSH로 접속하는 과정도 그닥입니다. 오래 쓰던 AWS는 무료 기간이 끝난 뒤의 비용이 부담스럽구요. Azure는 마지막으로 써본 지 너무 오래돼서 지금 사용성까지 평가하긴 어렵습니다. 오늘은 어디에 올릴지만 살펴봤으니, 다음에는 이런 서버에 올려 두면 쓸 만한 프로젝트도 소개해 보겠습니다.😉
