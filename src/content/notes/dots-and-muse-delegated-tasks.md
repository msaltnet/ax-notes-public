지난 글에서 dots 쪼쪼와 muse 뿡뿡이를 소개했는데요. 연결했으니 이제 일을 시켜봐야죠. 쪼쪼에게는 개발부터 메일 확인까지 이것저것 맡겼고, 뿡뿡이에게도 비슷한 일을 시켜보려고 했습니다. 무료라고 너무 신난 것 같기도 하네요ㅋ

## 무슨 일을 맡겼냐면

쪼쪼에게 맡겨둔 일을 정리해 달라고 했더니 크게 여섯 가지였습니다. 시간은 모두 한국시간입니다.

1. **SMTM 개발·개선.** LLM 기반 트레이딩 구조를 다듬고, 안정성과 테스트, 동작 상태를 확인하는 기능을 개선하도록 했습니다. 제가 승인한 PR은 병합하고 후속 작업도 이어가도록 맡겼습니다.
2. **AX Notes 앱·웹 개발.** 실제 글 피드 연결, 태블릿 대응, 메모·북마크·알림 기능을 개선하는 일입니다. 웹과 앱의 폰트·아이콘도 맞추고, 제가 남긴 이슈와 PR 피드백을 반영해 테스트 APK까지 준비하도록 했습니다.
3. **두 프로젝트 진행 보고.** 매일 08시와 20시에 프로젝트별 GitHub Issue로 진행 상황을 남기도록 했습니다. AX Notes는 앱과 웹 작업을 앱 저장소에서 함께 보고받습니다. 정상적으로 보고했다는 채팅은 반복하지 않기로 했고요.
4. **VOC 메일 확인·번역.** 매일 08시부터 24시까지 두 시간마다 고객 문의와 후속 답장, 반송 메일을 확인하고 한국어로 정리하도록 했습니다. 새 문의가 없어도 짧게 보고하되, 고객에게 답장을 보내는 일은 별도로 승인합니다.
5. **Watch-Go Threads 운영 지원.** 매일 09시와 21시에 게시물 아이디어를 다섯 개 정도 받고, 한글과 자연스러운 영어 초안, 사진·영상 소재도 제안받습니다. 기존 게시물과 반응을 참고해 중복을 줄이도록 했습니다. 게시글이나 댓글 번역도 따로 부탁하고요.
6. **경제 뉴스 브리핑.** 매일 07시, 14시, 20시에 국내·해외·정책과 지표로 나눠 새 소식과 출처를 받도록 했습니다.

이 밖에도 Threads 운영 지침 정리, 제가 승인한 고객 회신, 여행 일정 정리 같은 단건 작업도 맡겼습니다. 생각보다 시킬 일이 많더라구요.

## 개발 완료와 병합은 다른 이야기

진행 상황을 정리받은 시점에는 [SMTM PR #89](https://github.com/msaltnet/smtm/pull/89)가 구현과 테스트를 마치고 병합을 기다리고 있었습니다. [AX Notes PR #8](https://github.com/msaltnet/ax-notes/pull/8)은 최신 피드백 반영과 테스트 172개, 에뮬레이터 검증까지 끝냈다고 보고받았고요. 실제 기기에서 확인하고 병합하는 일은 아직 남아 있었습니다.

개발은 맡겨도 제가 확인할 순간은 남아 있습니다. PR을 검토하고, 앱을 직접 써보고, 고객에게 보낼 답장을 승인하는 일처럼요.

## muse는 쓰다가 접었습니다

뿡뿡이에게도 개발을 맡겨보려고 했는데, GitHub 커넥터 연결이 잘 안됐습니다. 연결부터 매끄럽지 않으니 작업을 이어가기 어려웠고요. 응답도 매우 오래 걸릴 때가 있었습니다. 무려 **20시간 뒤에 답이 온 적도 있어요.** 기다리다 보면 제가 뭘 부탁했는지부터 다시 떠올려야 합니다ㅋ

![Muse가 예약 작업을 소개하고 GitHub 인증 후 PR 작업을 이어가겠다고 안내하는 대화 화면](./assets/dots-and-muse-delegated-tasks/muse-scheduling-and-github.webp)

제가 원하는 개발 흐름은 결과를 보고 피드백을 주고, 다시 수정하는 식인데요. 답을 기다리는 시간이 길어지니 그 흐름이 끊겼습니다. 결국 muse는 사용하다가 접었습니다.

## 개발보다는 일정과 예약 쪽일지도

써보면서 받은 인상은 muse가 개발보다는 일정 관리나 예약 같은 일에 더 맞는 것 같다는 것입니다. 스스로 예약 작업과 아침 브리핑을 제안하기도 했고, 관심 있을 만한 행사를 찾아 알려주기도 했습니다.

![Muse가 관심 있을 만한 커뮤니티 행사를 소개하고 신청 링크를 찾아주겠다고 제안하는 화면](./assets/dots-and-muse-delegated-tasks/muse-event-assistance.webp)

당장 코드를 고치고 결과를 확인해야 하는 일보다, 미리 부탁해두고 나중에 챙겨주는 일에 더 어울린다는 느낌이었어요. 물론 제가 써본 범위에서의 생각입니다. 일정 관리나 예약을 충분히 써보고 내린 평가는 아니고요.

일단 개발과 반복 업무는 쪼쪼에게 맡겨보는 쪽으로 이어가려고 합니다. 다음에는 정해진 시간에 보고가 잘 오는지, 결과물이 실제로 쓸 만한지 이야기해보겠습니다.
